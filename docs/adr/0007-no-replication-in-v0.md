# 0007. 複製は v0 に含めず、Sink の差し替えで後から足せるようにする

- 状態: 承認（2026-10-01）
- 日付: 2026-09-30
- 関連: FR6 / 要件の未決事項 2

## 背景

要件の未決事項 2 は、複製を v0 に含めるかどうかだった。

## 決定

- v0 では実装しない。ティア `TierReplicated` の型は定義してある。`Config.Sinks` にクォーラム ack を返す `wal.Sink` を渡せば、そのティアが使えるようになる。
- ティアを使えるかどうかは起動時に決める。Sink がなければ、そのティアを求める Submit は `ErrTier` で拒否する。

## 結果

- 単一ノードの障害でファイルティアの実行は止まり、ディスクが無事なら再起動で再開する。ディスクを失うと実行も失われる。
- 複製を足しても、エンジン側の変更は要らない見込み（ack が返れば hold が解放される）。

## 検討した代替案

- Raft などを組み込む: v0 の範囲を大きく超え、性能目標の検証が後回しになる。
