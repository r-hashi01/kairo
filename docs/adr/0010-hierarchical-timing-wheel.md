# 0010. タイマーはシャードごとの階層タイミングホイールで持ち、OS タイマーは 1 本だけ張る

- 状態: 提案（v0 実装済み）
- 日付: 2026-09-30
- 関連: FR9 / 不変条件 6（ポーリングしない）

## 背景

大量のタイマー（承認のタイムアウト、リトライの待ち、待機）を O(1) で扱いたい。一方で、一定間隔で tick するホイールは、待機中のシャードを起こし続ける（ポーリングになる）。

## 決定

- 1 ms 単位、各レベル 64 スロット × 8 レベルの階層ホイールにする（`timerwheel`）。タイマーは相対値ではなく満了時刻の絶対値で置く。レベルは現在時刻との XOR の最上位ビットで決める。
- 各レベルに 64 ビットの占有ビットマップを持つ。これで次に何かが起きる時刻を数回のビット演算で求める。シャードは、その時刻に OS タイマーを 1 本だけ張る。
- ホイールが空ならタイマーを張らない。

## 結果

- 挿入と取消が約 7 ns。
- 何も起きないあいだ、シャードは一度も起きない（`TestIdleEngineDoesNotWake`）。
- 遠いタイマーは、上位レベルの境界で下位へ移し替えられる。そのぶん起床が少し増える。

## 検討した代替案

- ヒープ（`container/heap`）: 挿入と取消が O(log n)。
- 固定周期の tick: 実装は簡単だが、ポーリングになる。
- タイマーごとに `time.Timer` を作る: 実行数に比例してランタイムの負荷がかかる。
