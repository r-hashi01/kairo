# 0014. ランタイムは標準ライブラリだけで作る

- 状態: 承認（2026-10-01）
- 日付: 2026-09-30

## 背景

組み込み可能なライブラリとして、利用者の依存グラフを汚したくない。性能の特性も、自分で説明できる範囲に保ちたい。

## 決定

- `go.mod` に require を置かない。HTTP/2（h2c を含む）は `net/http` の `Protocols` で扱う。
- 依存を足す変更には ADR を書き、利用者の了承を得る。hook `guard-edit.sh` が、`go.mod` への追加に確認を求める。

## 結果

- gRPC、組み込み DB、JSON Schema のライブラリなどは使わない（→ 0005, 0009）。
- 一部を自前で実装する（タイミングホイール、MPSC キュー、フレーミング）。そのぶんテストで裏付ける。

## 検討した代替案

- 必要に応じて依存を足す: 個々には合理的でも、組み込み先の負担が積み上がる。
